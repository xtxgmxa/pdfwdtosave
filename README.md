# 比賽標題重新命名

把獎狀掃描檔一次丟進網頁，讀出上面的比賽標題，再依這個標題把每一頁存下來。

例如這張獎狀的標題是「114年新北菁英盃全國跆拳道錦標賽」，存檔時就用這個名稱。

檔案只在瀏覽器裡處理，不會上傳。

## 使用方式

1. 打開這個網頁。
2. 一次拖入多份 PDF、JPG 或 PNG。
3. 核對每一頁的比賽標題。辨識有誤時直接改字。
4. 選擇存成 JPG 圖片或單頁 PDF，然後下載。

同一批裡面標題相同的檔案，第二個起會自動加上 `_2`、`_3`，避免互相覆蓋。

辨識時會先濾掉彩色浮水印與外框，只留黑字，再把標題那一行單獨放大，用三種大小各讀一次後逐字投票。

- 找不到「○○年……賽」這種比賽名稱時，改用頁面上方字最大的一行，並標示「推測標題」。
- 同一批裡差一兩個字的標題，會互相比對、統一成多數的寫法。
- 下載過的標題會記在這個瀏覽器裡。之後辨識結果很接近時，直接換成記住的正確寫法。
- 每一頁都有「套用到全部」，一次把整批改成同一個標題。

第一次辨識會從網路下載約 2MB 的中文辨識資料，之後會留在瀏覽器裡。

## 放到 GitHub Pages

倉庫的 Settings → Pages，來源選 `main` 分支的根目錄。頁面位址會是 `https://<帳號>.github.io/<倉庫名>/`。
